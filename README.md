# Kayak Fishing Assistant

This small web page helps kayak fishermen plan their trip by showing weather, best fishing times and recommended baits for their location. It uses your browser's geolocation to determine latitude and longitude.

Due to environment restrictions the weather section requires a working OpenWeatherMap API key. Replace `YOUR_API_KEY` in `index.html` with your key.

Open `index.html` in a browser and click **Get Fishing Info** to generate advice based on the chosen date.
